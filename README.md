# Nexus Studio – Creative Digital Agency Website


A modern, minimalist, multi-page responsive website for a fictional creative digital agency called **Nexus Studio**. Built with **pure HTML5 & CSS3** (no frameworks or JavaScript), this project demonstrates strong semantic markup, mobile-first design, CSS Grid & Flexbox, smooth hover interactions, and a premium dark/red aesthetic.

Perfect portfolio piece for showcasing advanced HTML/CSS skills.

## 🌟 Features

- Multi-page structure: Home, About, Services, Portfolio, Contact
- Fully responsive (mobile, tablet, desktop)
- Mobile-first design with clean media queries
- Dark minimalist theme with vibrant red accents
- Fixed header with underline hover effect
- Full-screen hero with dark overlay
- Services & portfolio grids with hover lift & overlay reveal
- Testimonials with quote styling
- Styled contact form & embedded map
- Consistent branding across all pages
- Optimized images with `loading="lazy"`
- High accessibility & Lighthouse-friendly structure
